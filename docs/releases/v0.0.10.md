## BrushLLM Image Studio 0.0.10

- Image Studio focuses on local editing and batch export. The online AI tools and API settings have been removed.
- Tools and Settings open directly. Editing and export controls are visible before import, so you can prepare a task before selecting an image.
- Compact controls such as Mosaic Size use the available space more consistently.
- The macOS installer uses the standard drag-to-Applications disk image.

| System | Installer |
